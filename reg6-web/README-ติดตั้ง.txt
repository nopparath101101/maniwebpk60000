คู่มือติดตั้งเว็บสำนักงานไปรษณีย์เขต 6 บน Windows Server 2008 (IIS 7)
==================================================================

โฟลเดอร์นี้เป็นเว็บไซต์สาธารณะแบบไฟล์ธรรมดา (HTML/CSS/JavaScript) ทำงานบน Internet Explorer 7 ขึ้นไป
และ IIS 6/7 ของ Windows Server 2003/2008 ไม่ต้องมี ASP หรือฐานข้อมูลบนเครื่องนี้

ภาพรวม: ข้อมูลทั้งหมดอยู่ใน Supabase  เซิร์ฟเวอร์เว็บเครื่องนี้รันสคริปต์ sync\sync.vbs ทุก 5 นาที
ดึงข้อมูลล่าสุดมาสร้างไฟล์ js\content.js อัตโนมัติ ผู้เข้าชมจึงเห็นข้อมูลที่แก้ในระบบจัดการภายในไม่กี่นาที
(ผู้ใช้เปิดเว็บจากไฟล์ในเครื่องนี้เท่านั้น เบราว์เซอร์เก่าไม่ต้องคุยกับ Supabase เอง)

ขั้นตอนติดตั้ง
-------------
1) คัดลอกโฟลเดอร์ reg6-web ไปไว้ในเว็บไซต์ IIS เช่น C:\inetpub\wwwroot\reg6-web
   (IIS 7 ใช้ web.config ตั้งหน้าเริ่มต้นเป็น index.html และซ่อนโฟลเดอร์ sync ให้แล้ว
    IIS 6 ให้ตั้ง Default Document เป็น index.html เอง และอย่าวางโฟลเดอร์ sync ไว้ในเว็บไซต์)

2) ตั้ง Supabase ให้พร้อม (ดู README ในชุด reg6-admin) ต้องรันไฟล์ SQL ทั้ง 2 ไฟล์:
   supabase_schema.sql แล้วตามด้วย supabase_step2_server_sync.sql

3) เปิด TLS 1.2 บน Windows Server 2008 (ทำครั้งเดียว - Supabase รับเฉพาะ TLS 1.2 ขึ้นไป)
   ก) ติดตั้งอัปเดต KB4019276 "Update to add support for TLS 1.1 and TLS 1.2 in Windows Server 2008 SP2"
      จาก Microsoft Update Catalog (ต้องเป็น Server 2008 SP2 ถ้าติดตั้งไม่ผ่านให้ติดตั้ง KB4474419 และ KB4490628 ก่อน)
   ข) ดับเบิลคลิก sync\enable-tls12.reg (Run as administrator) แล้วรีสตาร์ตเครื่อง

4) ทดสอบการซิงก์
   ดับเบิลคลิก sync\run-sync-now.cmd
   - ขึ้น "สำเร็จ: อัปเดต ... content.js" = ใช้ได้ เปิดเว็บกด Ctrl+F5 เพื่อดูผล
   - ขึ้น "ไม่มีการเปลี่ยนแปลง" = ใช้ได้ (ข้อมูลตรงกับ Supabase อยู่แล้ว)
   - ขึ้น "ล้มเหลว: เชื่อมต่อ Supabase ไม่ได้" = ติดปัญหา TLS ดูหัวข้อ "ถ้าซิงก์ไม่ได้" ด้านล่าง
   ผลการทำงานทุกครั้งบันทึกใน sync\sync.log

5) ตั้งให้ซิงก์อัตโนมัติ
   คลิกขวา sync\install-task.cmd > Run as administrator (สร้าง Scheduled Task ชื่อ "Reg6 Sync Content" ทุก 5 นาที
   ทำงานด้วยบัญชี SYSTEM ไม่ต้องล็อกอินค้างไว้) เปลี่ยนความถี่ได้โดยแก้เลข 5 ในไฟล์นั้น

ถ้าซิงก์ไม่ได้ (ปัญหาที่พบได้บน Server 2008)
-------------------------------------------
Windows Server 2008 เก่ามาก แม้ติดตั้ง TLS 1.2 แล้วก็อาจต่อ Supabase ไม่ติด เพราะชุดเข้ารหัสที่ระบบรองรับ
ไม่ตรงกับที่ Supabase เปิดให้ ผมยังไม่ได้ทดสอบกับเครื่องจริง ถ้าเจอข้อความ secure channel / SSL มีทางออก 2 ทาง
  ก) รัน sync.vbs บนคอมพิวเตอร์ Windows 7 ขึ้นไป (หรือเครื่องที่ใช้ระบบจัดการอยู่) ที่ต่อเครือข่ายเดียวกัน
     แก้ OUTPUT_FILE ในไฟล์ sync.vbs ให้ชี้ไปที่ไฟล์บนเซิร์ฟเวอร์เว็บ เช่น \\SERVER\wwwroot\reg6-web\js\content.js
     (แชร์โฟลเดอร์ js ให้เขียนได้) แล้วตั้ง Scheduled Task บนเครื่องนั้นแทน
  ข) ใช้ปุ่ม "ส่งออก content.js" ในระบบจัดการ แล้วนำไฟล์ไปวางด้วยมือ

รูปภาพและไฟล์
-------------
- รูปหน้าแรก: images\hero.jpg
- รูปโปสเตอร์ข่าว: วางไว้ที่ images\news\ แล้วพิมพ์ชื่อไฟล์ในหน้าจัดการข่าว
- ไฟล์ดาวน์โหลดหนังสือเวียน/คู่มือ: วางในโฟลเดอร์ใดก็ได้ เช่น files\ แล้วใส่ลิงก์ เช่น files/doc001.pdf

ถ้าโฮสต์เว็บบน Vercel (แทนหรือควบคู่กับ Windows Server 2008)
------------------------------------------------------------
- อัปโหลดเนื้อหาในโฟลเดอร์ reg6-web "ทั้งหมด" ให้อยู่ที่ราก (root) ของโปรเจกต์ ได้แก่
    index.html, postal-systems.html, phone-numbers.html, css/, js/, images/, api/, vercel.json
  ถ้าอัปโหลดแค่ index.html หน้าเว็บจะไม่มีสไตล์ รูป และข้อมูล
- ไม่ต้องรัน sync.vbs: ไฟล์ api\content.js ดึงข้อมูลจาก Supabase เองทุกครั้งที่ผู้ใช้เปิดเว็บ (เก็บแคช 5 นาที)
  และ vercel.json เปลี่ยนเส้นทาง /js/content.js ไปที่ฟังก์ชันนี้ ข้อมูลที่แก้ในระบบจัดการจึงขึ้นเว็บภายในประมาณ 5 นาที
- โฟลเดอร์ sync, web.config และไฟล์นี้ ไม่ต้องอัปโหลด (.vercelignore ตั้งให้ข้ามไว้แล้ว)
- ตรวจหลัง deploy: เปิด https://<ชื่อเว็บ>.vercel.app/js/content.js ต้องเห็นโค้ดที่ขึ้นต้นด้วย  /* สร้างอัตโนมัติจาก Supabase ...

ปุ่ม "เข้าสู่ระบบ" ในเมนู
------------------------
เปิด js\data.js ใส่ที่อยู่ระบบจัดการที่ ADMIN_URL เช่น  var ADMIN_URL = "https://admin.example.com/";

หมายเหตุ
--------
- มุมโค้งและเงาแสดงบน IE9 ขึ้นไป บน IE7/8 เป็นมุมเหลี่ยมแต่ใช้งานได้
- Dashboard (Looker Studio) ที่ฝังด้วย iframe อาจแสดงไม่ได้บนเบราว์เซอร์เก่ามาก ปุ่ม "เปิดเต็มจอ" เปิดในหน้าต่างใหม่
- Windows Server 2008 หมดการสนับสนุนด้านความปลอดภัยจาก Microsoft แล้ว ควรวางแผนย้ายไประบบที่ใหม่กว่า
